# Eksplorasi Hugging Face: Sentiment Analysis Bahasa Indonesia

Repositori ini dibuat untuk memenuhi tugas eksplorasi ekosistem Hugging Face, menjalankan model NLP, dan melakukan inference menggunakan data uji mandiri.

## 🔗 Informasi Model
- **Nama Model:** `mdhugol/indonesia-bert-sentiment-classification`
- **Link Model:** [Hugging Face Hub - indonesia-bert-sentiment-classification](https://huggingface.co/mdhugol/indonesia-bert-sentiment-classification)
- **Kategori Task:** Text Classification (Sentiment Analysis)

## 🛠️ Persyaratan dan Cara Menjalankan (Setup)
Pastikan Python sudah terinstal di environment Anda (disarankan menggunakan Google Colab atau Virtual Environment lokal).

1. Clone repositori ini:
   `git clone https://github.com/USERNAME_ANDA/NAMA_REPO_ANDA.git`
2. Install dependencies yang dibutuhkan:
   `pip install transformers torch`
3. Jalankan script:
   `python hf_sentiment_analysis.py` (atau jalankan cell di Jupyter Notebook)

## 🧪 Contoh Input dan hasil
Model diuji menggunakan 3 kalimat buatan sendiri yang mewakili sentimen Positif, Negatif, dan Netral.
